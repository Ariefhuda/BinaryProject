# 🗑️ BinaryProject: Sistem Pelaporan Kebersihan Kota Medan

**BinaryProject** adalah platform berbasis web untuk melaporkan lokasi kotor, tumpukan sampah, atau masalah kebersihan lainnya di sekitar kota **Medan**. Sistem ini menghubungkan masyarakat, admin, dan dinas terkait untuk menindaklanjuti laporan secara cepat, transparan, dan terdokumentasi dalam bentuk artikel berita.

Dibangun dengan **Laravel 11** untuk memastikan keamanan data, performa tinggi, dan skalabilitas sistem.

## 📂 Struktur Database Utama

Sistem ini menggunakan relasi tabel yang efisien:
- `users`: Data pengguna (role: admin, user).
- `reports`: Tabel utama laporan (lokasi, deskripsi, status, koordinat latitude/longitude).
- `report_images`: Galeri foto bukti per laporan.
- `categories`: Kategori masalah (Sampah Rumah Tangga, Limbah Bangunan, Selokan Tersumbat, dll).
- `articles`: Artikel berita hasil tindak lanjut laporan (CRUD).
